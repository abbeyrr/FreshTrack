# Project Description: FreshTrack

FreshTrack addresses a common household problem: food is bought, forgotten, and thrown away. The Windows desktop app records food names, categories, quantities, purchase and expiry dates. It shows factual expiry status alongside model-based waste-risk priority, transfers purchased shopping-list items into inventory, and records quantities used or wasted. Category and monthly summaries make waste visible.

The target user is a household member managing a shared pantry or fridge on one Windows PC. The four functional WPF screens are Inventory, Expiry Dashboard, Shopping List, and Reports. The app stores its data with EF Core in a local SQLite file. Reports also includes an ML.NET demonstration: a logistic regression model trained and tested on 50,000 generated records displays individual simulated waste scores and category summaries for current stock. Actual expiry status is calculated from dates. Those synthetic scores are not validated predictions of real household behaviour. The project includes first-run demonstration data and NUnit tests. See `ReadMe.md` for running and demonstration instructions and `Report_Handoff.md` for report-writing evidence.
